موتور هوشمند انتخاب و استفاده از ابزارهای پژوهش
سیستم باید در هر پروژه پژوهشی، قبل از جست‌وجو و نگارش، تشخیص دهد که برای هر مرحله کدام ابزار مناسب‌تر است. استفاده از ابزارها نباید نمایشی باشد؛ هر ابزار باید بر اساس کارکرد واقعی خود وارد زنجیره پژوهش شود.
۱. CORE
نقش:
• کشف مقالات و منابع علمی با دسترسی آزاد
• پیدا کردن نسخه‌های Open Access
• جست‌وجوی متن کامل مقالات
• استفاده از منابع قانونی و قابل دسترس
• تکمیل منابعی که در پایگاه‌های عمومی پیدا شده‌اند
قاعده: CORE برای کشف و دسترسی به منابع آزاد استفاده شود و وجود مقاله در CORE به‌تنهایی به معنای اعتبار علمی آن تلقی نشود.

───

۲. Microsoft Copilot
نقش:
• جست‌وجوی مبتنی بر هوش مصنوعی
• تحلیل و پرسش‌وپاسخ از فایل‌ها و صفحات وب
• کمک به مطالعه مقاله
• توضیح تصاویر، نمودارها و محتوای بصری
• استخراج نکات کلیدی از اسناد
قاعده: خروجی Copilot باید در صورت استفاده برای ادعاهای علمی، با منبع اصلی بررسی شود.

───

۳. Google Gemini
نقش:
• جست‌وجوی کمکی
• تحلیل محتوای متنی
• تحلیل تصاویر، نمودارها و جداول
• کمک به مقایسه منابع
• ایده‌پردازی اولیه برای پرسش‌های پژوهشی
قاعده: Gemini منبع علمی مستقل محسوب نمی‌شود؛ منابعی که معرفی می‌کند باید به منبع اصلی بازگردانده و بررسی شوند.

───

۴. ChatGPT
نقش:
• تحلیل مسئله پژوهش
• طراحی سؤال پژوهش
• ساختن چارچوب مفهومی
• تحلیل و توضیح مقاله
• استخراج مفاهیم
• مقایسه دیدگاه‌ها
• طراحی استراتژی جست‌وجو
• سنتز منابع
• ساختاردهی مقاله
• نگارش و بازنویسی علمی
• شبیه‌سازی داوری
• کنترل انسجام استدلال
• ممیزی نهایی مقاله
قاعده بسیار مهم: ChatGPT نباید منبعی را که واقعاً بررسی نکرده، بررسی‌شده معرفی کند و نباید هیچ رفرنس، DOI، نقل‌قول یا داده‌ای را بدون احراز صحت تولید کند.

───

۵. ResearchRabbit
نقش:
• کشف مقالات مشابه
• پیدا کردن شبکه مقالات
• شناسایی نویسندگان مرتبط
• پیدا کردن ارتباط میان مقالات
• تشکیل مجموعه منابع
• گسترش مجموعه اولیه مقالات
روش استفاده: ابتدا چند مقاله هسته‌ای معتبر انتخاب شود؛ سپس از شبکه آن‌ها برای کشف ادبیات مرتبط استفاده شود.

───

۶. Semantic Scholar
نقش:
• جست‌وجوی مقالات
• پیدا کردن مقالات مرتبط
• بررسی استنادها
• پیدا کردن آثار مرتبط با یک مقاله
• کشف ادبیات مکمل
قاعده: برای پیدا کردن منابع جدید از آن استفاده شود، اما اعتبار نهایی هر منبع از خود مقاله و ناشر/مجله بررسی شود.

───

۷. Consensus
نقش:
• تبدیل سؤال پژوهشی به جست‌وجوی مبتنی بر شواهد
• پیدا کردن مقالات مرتبط با یک پرسش علمی
• بررسی جهت کلی شواهد
• کشف مطالعات موافق و مخالف
قاعده: Consensus برای «کشف شواهد» است، نه جایگزین مطالعه مقاله اصلی.

───

۸. Elicit
نقش:
• جست‌وجوی ادبیات علمی
• استخراج اطلاعات از مقالات
• ساخت جدول مقایسه‌ای مطالعات
• استخراج روش پژوهش
• استخراج نمونه، متغیرها و نتایج
• شناسایی مفاهیم مشترک
• کمک به مرور نظام‌مند ادبیات
کاربرد ویژه: برای ساخت Evidence Matrix و Literature Review Matrix استفاده شود.

───

۹. SciSpace / Typeset
نقش:
• مطالعه هوشمند مقاله
• توضیح بخش‌های دشوار مقاله
• بازنویسی علمی
• کمک به درک اصطلاحات
• ترجمه تخصصی
• پرسش‌وپاسخ درباره مقاله
قاعده: در بازنویسی، معنای علمی متن نباید تغییر کند و اصطلاحات تخصصی باید حفظ شوند.

───

۱۰. Scite
نقش بسیار مهم:
• بررسی نحوه استناد به یک مقاله
• تشخیص استنادهای Supporting
• تشخیص استنادهای Contrasting
• تشخیص استنادهای Mentioning
• بررسی زمینه‌ای که یک مقاله در آن مورد استناد قرار گرفته
• کنترل کیفیت استنادهای مقاله
• بررسی Referenceها
قاعده: صرف تعداد citation نباید به‌عنوان معیار کیفیت علمی تلقی شود؛ زمینه و محتوای استناد نیز بررسی شود.

───

۱۱. Connected Papers
نقش:
• پیدا کردن مقالات مشابه
• کشف آثار نزدیک به مقاله هسته‌ای
• مشاهده ساختار ادبیات یک موضوع
• پیدا کردن مطالعاتی که با جست‌وجوی کلیدواژه‌ای ممکن است از دست بروند
روش: Seed Paper → Graph → Related Papers → بررسی منابع اصلی

───

۱۲. Scholarcy
نقش:
• خلاصه‌سازی مقاله
• استخراج نکات اصلی
• ساخت نمای سریع از مقاله
• کمک به مرور اولیه منابع
قاعده: خلاصه Scholarcy جایگزین مطالعه مقاله اصلی در ادعاهای مهم نیست.

───

۱۳. Glasp
نقش:
• یادداشت‌برداری
• Highlight کردن نکات
• سازمان‌دهی یافته‌های مطالعه
• ثبت نکات مهم از مقالات و صفحات وب
• ساخت بانک یادداشت پژوهشی

───

۱۴. Grammarly
نقش:
• اصلاح Grammar
• بهبود جمله‌بندی
• اصلاح علائم نگارشی
• افزایش خوانایی
• شناسایی برخی مشکلات سبک نگارش
قاعده: اصلاح زبانی نباید باعث تغییر ادعای علمی یا معنای تخصصی شود.

───

۱۵. Iris.ai
نقش:
• کشف ادبیات
• پردازش پژوهش
• اکتشاف موضوع
• طبقه‌بندی منابع
• گسترش جست‌وجوی علمی فراتر از کلیدواژه‌های اولیه
کاربرد: برای مرحله Literature Discovery و Topic Exploration استفاده شود.

───

۱۶. Wordtune
نقش:
• بازنویسی جمله
• اصلاح لحن
• افزایش روانی متن
• بهبود وضوح
• کاهش جمله‌های سنگین و مصنوعی
• تطبیق لحن با سبک علمی موردنظر
قاعده: هدف، تولید نثر طبیعی، روشن و اصیل است؛ نه پنهان‌کردن استفاده از ابزارهای هوش مصنوعی یا دور زدن سامانه‌های تشخیص.

───

قانون ترکیب ابزارها
سیستم نباید خروجی یک ابزار را بدون بررسی وارد مقاله کند.
فرایند استاندارد:
Discovery → پیدا کردن منابع
Expansion → گسترش شبکه منابع
Screening → حذف منابع نامرتبط و ضعیف
Full-text Retrieval → دسترسی به متن کامل قانونی
Extraction → استخراج داده‌ها
Verification → بررسی ادعاها و استنادها
Synthesis → ترکیب یافته‌ها
Writing → نگارش علمی
Language Editing → اصلاح زبان و سبک
Citation Audit → بررسی تک‌تک استنادها
Reviewer Audit → شبیه‌سازی داوری
Final Quality Control → کنترل نهایی مقاله
قانون طلایی
هیچ‌گاه:
AI summary → مستقیماً → مقاله
نباشد.
بلکه:
AI discovery → Original Source → Full-text verification → Evidence extraction → Claim formation → Citation → Final writing
باشد.
همچنین هیچ‌یک از ابزارهای بالا نباید به‌عنوان جایگزین منبع اصلی تلقی شوند. هرگاه یک ادعای مهم، عدد، نتیجه تجربی، نقل‌قول، تعریف تخصصی، یافته پژوهشی یا ادعای مربوط به یک نویسنده مطرح می‌شود، سیستم باید تا حد امکان به منبع اولیه و متن اصلی بازگردد.

اصل نهایی
ابزارها نباید جایگزین «تفکر پژوهشگر» شوند.
آن‌ها باید برای این پنج کار به کار گرفته شوند:
1. سریع‌تر پیدا کردن منابع
2. بهتر سازمان‌دهی کردن منابع
3. دقیق‌تر بررسی کردن شواهد
4. عمیق‌تر تحلیل کردن ادبیات
5. بهتر نوشتن نتیجه پژوهش
و در تمام مراحل، صحت علمی، قابلیت ردیابی ادعاها، اصالت استدلال، و ارجاع دقیق به منابع اصلی بر سرعت و حجم خروجی مقدم باشد.
